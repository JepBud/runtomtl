# RunToMTL Race Control

Live leg tracker for our RunToMTL relay team (Toronto to Montreal, 67 legs).

- Everyone can follow the race: current leg, runner, ETAs for swaps, the ferry and the finish.
- Tap **Unlock** and enter the team PIN to log handoffs, splits, notes and edits.

Race data lives in Supabase (`config.js` points to it). The page is plain HTML hosted on GitHub Pages.
